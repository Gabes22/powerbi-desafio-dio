# Desafio de Projeto Power BI - DIO

Repositório desenvolvido como parte da Formação Power BI Analyst da DIO, focado na criação de relatórios analíticos detalhados de vendas e lucro.

## 🚀 Funcionalidades do Relatório
- **Página 1**: Visão geral executiva com indicadores de desempenho e navegação.
- **Página 2**: Relatório de lucro detalhado contendo:
  - Filtro de anos em formato de mosaico.
  - Gráfico de decomposição (Decomposition Tree) ramificado por Ano e País.
  - Gráfico de área para análise de produtos.
  - Treemap para distribuição por segmentos.
  - Gráfico em cascata (Waterfall) para variação trimestral.
